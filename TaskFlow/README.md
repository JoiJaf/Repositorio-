TaskFlow

Aplicación web full stack diseñada para la gestión de tareas académicas, con sistema de roles (profesor/estudiante) y seguimiento del rendimiento. El sistema permite a los profesores gestionar cursos y asignaciones, mientras que los estudiantes pueden visualizar sus tareas pendientes y monitorear su progreso mediante indicadores visuales.


Tecnologías utilizadas
Frontend: HTML5, CSS3, JavaScript
Backend: PHP
Frameworks: React.js, Laravel
Base de datos: MySQL
Arquitectura: Cliente-servidor
API REST

Funcionalidades principales:
Autenticación y roles
Inicio de sesión con diferenciación de roles (profesor / estudiante)
Control de acceso según tipo de usuario

Gestión de cursos y tareas (Profesor)
Creación y administración de cursos
Asignación de tareas a estudiantes
Gestión de entregas y seguimiento académico

Panel de estudiante
Visualización de tareas pendientes
Seguimiento del rendimiento académico
Organización de actividades por curso

Sistema de semáforo (estado de tareas)
Indicadores visuales para el estado de las tareas:
🟢 Completado
🟡 En progreso
🔴 Pendiente o atrasado
