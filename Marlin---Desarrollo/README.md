Marlin App – Plataforma de Entregas y Comercio Local

Aplicación móvil orientada a la gestión de pedidos y entregas de productos en Puntarenas, diseñada para conectar usuarios, comercios y repartidores en una misma plataforma. 
El sistema permite la compra de productos de distintas categorías (supermercado, ferretería, ropa, entre otros), gestión de tiendas por parte de comercios y distribución de pedidos mediante repartidores, integrando funcionalidades similares a plataformas como Uber Eats.

Tecnologías utilizadas
Mobile: React Native
Backend: Django
Base de datos: Mysql Server
APIs: Geolocalización API

Funcionalidades principales:

Usuario (Cliente)
Registro e inicio de sesión
Búsqueda de productos por categorías
Sistema de filtros para navegación
Gestión de direcciones de entrega
Simulación de flujo de compra (carrito, pedidos)

Usuario Comercio (Dueño de tienda)
Registro de tiendas dentro de la plataforma
Gestión de catálogo de productos
Configuración de precios, cantidades y variantes
Administración de pedidos recibidos

Usuario Repartidor
Recepción de pedidos disponibles
Gestión de entregas
Sistema de comisiones por envío

Sistema de geolocalización
Visualización de entregas en mapa
Seguimiento de pedidos en tiempo real

Conceptos aplicados
Desarrollo de aplicaciones móviles
Arquitectura multi-rol (cliente, comercio, repartidor)
Modelado de sistemas de marketplace
Integración de geolocalización y mapas
Manejo de flujo de pedidos (order lifecycle)
Diseño de experiencia de usuario orientada a entregas
