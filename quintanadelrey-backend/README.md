"# quintanadelrey-backend" 

Backend desarrollado para la gestión de restaurantes y sus menús, permitiendo la administración de información mediante una API estructurada. El sistema permite registrar múltiples restaurantes y gestionar sus platillos asociados, aplicando relaciones entre entidades y manejo de datos persistentes.

Tecnologias:
PHP, JSON, MYSQL

Funcionalidades:
CRUD completo de restaurantes
CRUD de platillos asociados a cada restaurante
Relación entre entidades (restaurante → menú)
Validación básica de datos en endpoints
Estructuración de rutas y controladores
